# Contributing to Daynizer

Thanks for your interest in Daynizer.

**Bug reports and feature ideas are welcome.** Open an
[issue](https://github.com/precisioncrab/daynizer-desktop/issues) and describe what happened or what you'd
like Daynizer to do. Questions about setting up a server go to the
[connection guide](https://precisioncrab.com/apps/daynizer/connect/).

**Code contributions aren't accepted.** Daynizer is written and maintained by Precision Crab, which keeps
all of its code under one owner. Please don't send pull requests, patches or code snippets, in issues
either: describe the problem or the idea in words, and the fix gets written here.

Daynizer stays free and open source under the GPL-3.0-or-later license (see [LICENSE](LICENSE)), so
you're free to read, build and modify it under that license.
